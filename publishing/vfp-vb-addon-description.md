# StackAnvil Bedrock Addon for ViaFabricPlus

This is StackAnvil's experimental build of [ViaFabricPlus Bedrock](https://github.com/ViaVersionAddons/viafabricplus-bedrock). It adds Bedrock Edition support to ViaFabricPlus on the Minecraft Java client. StackAnvil maintains this patched build while changes are under upstream review. It is not an official ViaVersion release.

## Install

Use Minecraft Java Edition 26.3 with Fabric Loader. Install ViaFabricPlus and this add-on in the same client. Use the matching StackAnvil ViaFabricPlus JAR from the [same GitHub release](https://github.com/StackAnvil/patches/releases). If your launcher installs the upstream ViaFabricPlus JAR automatically, replace it with the StackAnvil JAR. Keep only one ViaFabricPlus JAR in the mods folder. The add-on includes the patched ViaBedrock and CubeConverter libraries. Do not install those library JARs as separate Fabric mods.

## Bedrock features in this build

- Connect to Bedrock servers and sign in with your Microsoft account for online mode servers.
- Open Bedrock Friends and Realms from the ViaFabricPlus screen. View friends, requests, joinable worlds, parties, and Realms.
- Render Bedrock custom entities and player skins.
- Use the classic Dressing Room to select Steve or Alex, or import a skin and cape.

Some Bedrock behavior remains experimental. Test this build before you rely on it for a long session.
