# StackAnvil ViaFabricPlus

This is StackAnvil's experimental build of [ViaFabricPlus](https://github.com/ViaVersion/ViaFabricPlus) for Minecraft Java Edition 26.3. It provides a separately identified ViaFabricPlus JAR for the [matching StackAnvil Bedrock add-on](https://modrinth.com/mod/stackanvil-bedrock-addon). The current ViaFabricPlus patch changes the build version and vendor information. ViaFabricPlus gameplay features remain those of upstream. The Bedrock changes are in the separate add-on and its bundled libraries. This is not an official ViaVersion release.

## Install

Use Minecraft Java Edition 26.3 with Fabric Loader and Java 25. Install this ViaFabricPlus JAR and the StackAnvil Bedrock add-on JAR from the [same StackAnvil release](https://github.com/StackAnvil/patches/releases). Keep only one ViaFabricPlus JAR in your mods folder. The add-on embeds its patched ViaBedrock and CubeConverter libraries. Do not install those libraries as separate Fabric mods.

ViaFabricPlus lets the Java client join servers that run other Minecraft versions. The matching Bedrock add-on adds Bedrock server support and experimental social, Realm, entity, and skin features. See the add-on page for details.
