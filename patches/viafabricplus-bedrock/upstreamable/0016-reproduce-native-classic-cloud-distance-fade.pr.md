Java 26.3 uses a separate cloud range that reaches 2048 blocks with the current settings. This leaves clouds in the matched Hive and CubeCraft lobby views after the native client has faded them out.

This patch reproduces the classic Bedrock vertex alpha calculation. Clouds stay opaque through 0.9 times the cloud distance and fade to zero at 1.9 times that distance. It computes spherical distance per vertex, then lets the rasterizer interpolate alpha. The fragment shader preserves cloud RGBA without applying Java's fade again.

The native evidence targets official Bedrock 1.26.51.1, protocol 2193. The executable SHA-256 is `537c0aee2e79afbdc94b44b28e00f466ae62bc50e2733d953b430db9dbaa9ee7`. The `Clouds.material.bin` SHA-256 is `99cc015e2668a381f759a1aa3571b30926c52ac0724451a2938dbfdf62363818`. Both transparent vertex instancing variants use this formula, and the fragment shader forwards RGBA.

A one-shot hardware observation of native gameplay cloud draw `144714d90` records a configured ten-chunk view distance, internal camera range 176 blocks, margin distance 160 blocks, and final cloud distance 160 blocks. The ordinary high-range camera calculation removes an internal extra chunk. Java already supplies the effective terrain distance, so subtracting another chunk would shorten the result incorrectly. The observation uses the original native code and a private local world. Native binaries, shader exports, captures, authentication data and screenshots remain private.

Activation follows the existing accepted Bedrock rendering context, including direct connections and supported converted server packs. It requires Fancy clouds, dry Overworld air, at least five effective chunks, and no blindness, darkness or boss fog. The other cases retain their existing rendering path because their native distance inputs or effects remain unverified. Cloud height and dimension behavior are unchanged. The lack of clouds in these lobby views does not establish a server cloud-disable flag.

The four dedicated Fancy pipelines preserve color targets, shader defines, uniform layouts, depth and stencil state, culling, vertex formats, topology and push constants. OIT depth bounds retains its existing unfaded behavior. The fog hook replaces the cloud distance before Java's later boss-fog adjustment. No Flat-cloud pipelines are registered.

Five focused regressions pass. A private Mesa GPU check compiles the actual authored vertex shader and compares 20,160 vertices with an independent float32 native fade reference. It covers all six faces, packed geometry flags, fractional offsets, partial alpha, fade boundaries and OIT depth bounds. Maximum channel error is 1.83e-7. These checks verify supplied inputs and render-state preservation, not complete cloud geometry or sky parity.
