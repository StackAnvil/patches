Every file is also under **Assets** on the [latest StackAnvil release on GitHub](https://github.com/StackAnvil/patches/releases/latest).

## Libraries and builds

- **ViaBedrock and CubeConverter:** Download their JARs if you need those libraries for a project. They are not standalone Fabric mods.
- **Maven dependencies:** Use the [StackAnvil Maven repository](https://stackanvil-maven.pistonmaster.net/) for patched artifacts. The [Maven and Javadocs guide](/libraries/) has a Gradle example, direct artifact links, and API references. Get ViaFabricPlus from [upstream Maven](https://repo.viaversion.com/com/viaversion/viafabricplus/).

<Callout type="warn">
  StackAnvil builds include experimental changes that may still be under upstream review. Test them
  before relying on them for a long play session or a production server. StackAnvil is independent
  of ViaVersion.
</Callout>

To make your own build, see [Build from source](/build-from-source/).
