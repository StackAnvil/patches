StackAnvil stores patch files in this repository. Generated source checkouts stay under `.worktrees/` on your machine.

| Project                      | Upstream                                                                                            | JDK | Build command                         |
| ---------------------------- | --------------------------------------------------------------------------------------------------- | --- | ------------------------------------- |
| ViaBedrock                   | [ViaVersionAddons/ViaBedrock](https://github.com/ViaVersionAddons/ViaBedrock)                       | 25  | `bun run build viabedrock`            |
| ViaFabricPlus Bedrock add-on | [ViaVersionAddons/viafabricplus-bedrock](https://github.com/ViaVersionAddons/viafabricplus-bedrock) | 25  | `bun run build viafabricplus-bedrock` |
| CubeConverter                | [oryxel1/CubeConverter](https://github.com/oryxel1/CubeConverter/tree/vv-json)                      | 17  | `bun run build cubeconverter`         |
| ViaProxy                     | [ViaVersion/ViaProxy](https://github.com/ViaVersion/ViaProxy)                                       | 25  | `bun run build viaproxy`              |

## ViaBedrock

The [ViaBedrock patch series](https://github.com/StackAnvil/patches/tree/main/patches/viabedrock) is the core of the Bedrock work.

## ViaFabricPlus Bedrock add-on

The [add-on patch series](https://github.com/StackAnvil/patches/tree/main/patches/viafabricplus-bedrock) connects Bedrock support to the Fabric client. The [player guide](/getting-started/) explains installation.

## CubeConverter

The [CubeConverter patch series](https://github.com/StackAnvil/patches/tree/main/patches/cubeconverter) builds a library used by ViaBedrock. It builds before dependent projects.

## Foundry companion

The [Foundry companion](https://github.com/StackAnvil/patches/tree/main/mods/foundry-companion) is a StackAnvil-owned Fabric mod, not a patch target. It starts [Bedrock Foundry](https://github.com/StackAnvil/BedrockFoundry) servers from Java Edition and joins them through the add-on. `bun run build all` builds it after the add-on. The [player guide](/getting-started/#host-a-server-with-your-marketplace-add-ons) explains its use.

## ViaFabricPlus

StackAnvil downloads a pinned [upstream Jenkins build](https://ci.viaversion.com/job/ViaFabricPlus/) for the Bedrock add-on. The [pin](https://github.com/StackAnvil/patches/blob/main/viafabricplus.json) records its build number, commit and checksums. Run `bun run build viafabricplus` to download and verify it. This command does not build ViaFabricPlus source.

## ViaProxy

The [ViaProxy patch series](https://github.com/StackAnvil/patches/tree/main/patches/viaproxy) builds against the patched ViaBedrock dependency.

The patch dependency order and upstream commits live in [`targets.json`](https://github.com/StackAnvil/patches/blob/main/targets.json).

For published artifact coordinates and API references, see [Maven and Javadocs](/libraries/).
