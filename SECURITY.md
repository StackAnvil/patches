# Security policy

Please do not post a security vulnerability in a public issue or PR. Use GitHub's **Report a vulnerability** action in the affected StackAnvil repository. Include the affected project, patch, impact, and steps to reproduce. We will acknowledge the report and coordinate a fix with upstream when the issue also affects upstream.

Do not commit Bedrock account tokens, proxy certificates, traffic captures, or session logs. The development tools keep local data under ignored directories. Remove private data before attaching logs to an issue.
